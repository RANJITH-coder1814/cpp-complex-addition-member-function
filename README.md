# Complex Number Addition using Member Function (C++)

This repository contains a C++ program that demonstrates how to add two complex
numbers using a **class member function**.

The program follows basic **Object-Oriented Programming (OOP)** principles.

---

## 📌 Program Description
- A `complex` class is defined with real and imaginary parts
- A member function `add()` is used to add two complex numbers
- The result is stored in a new complex object and displayed

---

## 🧠 Concepts Used
- Classes and Objects
- Constructors
- Member Functions
- Encapsulation
- Object-Oriented Programming (OOP)

---

## 🧾 Sample Input
Complex number 1: 10 + 5i
Complex number 2: 3 + 4i
First complex number is: 10 + 5i
Second complex number is: 3 + 4i
Sum is: 13 + 9i
